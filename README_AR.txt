بوت ديسكورد متكامل — إعداد سريع على Windows
===========================================

المميزات:
- إدارة: ban / kick / timeout / clear / warn + سجل تحذيرات
- قفل وفتح الرومات + slowmode
- رتب عبر Slash Commands
- تذاكر بزر وفتح روم خاص وإغلاقه
- تقديمات بنموذج Modal + قبول/رفض + رتبة عند القبول
- ترحيب/توديع + Auto Role
- Logs للرسائل المحذوفة والمعدلة ودخول/خروج الأعضاء
- AutoMod للسبام والمنشنات وروابط الدعوات والروابط العامة اختياريًا
- اقتراحات مع تصويت
- أوامر معلومات وصورة شخصية وإعلانات Embed

1) تثبيت Node.js
نزّل إصدار Node.js LTS من الموقع الرسمي nodejs.org وثبته.

2) إنشاء البوت
- افتح Discord Developer Portal
- New Application ثم Bot
- انسخ Token ولا تشاركه مع أي شخص.
- من صفحة Bot فعّل SERVER MEMBERS INTENT و MESSAGE CONTENT INTENT.

3) ملف .env
انسخ .env.example وغيّر اسمه إلى .env
ثم ضع:
DISCORD_TOKEN=توكن_البوت
CLIENT_ID=Application_ID
GUILD_ID=Server_ID

4) config.json
فعّل Developer Mode في Discord وانسخ IDs للرومات والرتب المطلوبة.
اترك أي ID فارغ إذا لم ترد استخدام الميزة.

5) تثبيت وتشغيل
افتح CMD داخل مجلد المشروع ونفذ:
npm install
npm run deploy
npm start

6) دعوة البوت
من Developer Portal > OAuth2 > URL Generator / Installation
أضف bot + applications.commands وأعطه الصلاحيات اللازمة.
للتجربة فقط يمكنك إعطاؤه Administrator، لكن الأفضل لاحقًا تحديد الصلاحيات المطلوبة فقط.

ملاحظة مهمة:
لا تضع Token داخل config.json ولا ترسله لأحد. إذا انكشف، اعمل Reset Token فورًا.


7) الإعداد التلقائي الكامل (الجديد)
بعد تشغيل البوت وتسجيل الأوامر، اكتب داخل السيرفر:
/setup_server
ثم اضغط زر "إنشاء وتجهيز السيرفر".

سيقوم البوت بإنشاء هيكل عام متكامل: معلومات، مجتمع، ألعاب، دعم، صوتيات، إدارة، تذاكر، مع رتب الإدارة والدعم وMember وVIP، ثم يربط IDs تلقائياً داخل config.json ويرسل لوحات التذاكر والتقديمات والقوانين.

مهم:
- الأمر لا يحذف الرومات أو الرتب الموجودة مسبقاً.
- ارفع رتبة البوت فوق الرتب التي تريد منه إدارتها.
- أثناء الإعداد الأول فقط، Administrator هو الأسهل. بعد الانتهاء يمكنك تقليل صلاحيات البوت إذا رغبت.
- لو عدت وشغلت /setup_server مرة ثانية، يحاول إعادة استخدام الرومات والرتب التي تحمل نفس الأسماء بدلاً من تكرارها.


=== تذكير ذكر الله اليومي ===
- ينشئ /setup_server روم باسم: ذكر-الله
- يرسل تذكيراً يومياً الساعة 09:00 صباحاً بتوقيت الرياض.
- يوم الجمعة يرسل: اللهم صلِّ وسلم على نبينا محمد ﷺ 🤍✨
- باقي الأيام يرسل ذكراً عشوائياً من قائمة الأذكار.
- يمكن تغيير الوقت من config.json داخل reminders.dhikrTime بصيغة HH:MM.
- يجب أن يبقى البوت شغالاً حتى تعمل الرسائل المجدولة.
